
# விஶ்வரூப யாத்ரை / விஶ்வரூப தர்ஶனம்

தமது சாதுர்மாஸ்ய வ்ரதத்தின்போது பரமஹம்ஸ ஸந்ந்யாஸிகள் ஒரே ஊர் எல்லைக்குள் இருப்பர். இந்த வ்ரதத்தின் பூர்த்தியைக் குறிக்கும்படி இந்த எல்லையை தாண்டுவது விஶ்வரூப யாத்ரை எனப்படும்.

அச்சமயம் கீதையில் சொல்லப்பட்ட பகவானின் விஶ்வரூப தர்ஶனத்தை படிப்பது மரபு. அத்துடன் மஹாபாரதத்திலேயே வேறு இரண்டு விஶ்வரூப தர்ஶனங்களும் சொல்லப்பட்டுள்ளன. பக்தர்களின் பாராயண சௌகரியத்திற்காக அவை உள்ளடங்கியதான இந்த கோப்பு பல லிபிகளில் வெளியிடப்படுகிறது.

# Vishvarupa Yatra / Vishvarupa Darshana

During their Chaturmasya Vrata, Paramahamsa sannya‌si‌-s stay within one village boundary. The crossing of this boundary signifying the completion of this Vrata is called Vishvarupa Yatra. 

On this occasion, it is tradition to read the Vishvaru‌pa Darshana of Bhagava‌n described in the Gi‌ta‌. Along with that, there are two other Vishvaru‌pa Darshana-s described in the Maha‌bha‌rata. This document comprising those is published in multiple scripts for the convenience of pa‌ra‌yana of devotees.
